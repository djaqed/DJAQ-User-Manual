# DJAQ™ User Manual — GitHub Pages edition (full interactive rebuild)

This is a from-scratch static rebuild of the live `djaq-help` app (the Next.js/Cloudflare
project in your working folder), not the earlier flat single-view export. It reproduces:

- The topbar: hamburger menu (mobile), brand button, search box, "↓ Offline HTML" download
  button, "↗ Share" button, and the ONLINE status indicator.
- All three views from the original app: **Manual** (25 chapters with the hero, system specs,
  and warning notice), **Diagnostics** (12 reference codes), and **Quick ref** (13 rules,
  the resource-check panel, and the compatibility note).
- Live search that filters chapters or diagnostic codes as you type, with a result count.
- Chapter deep-linking via `#chapter-05`-style anchors, "Copy link" per chapter, and hash-based
  routing on load.
- The "↓ Offline HTML" button, which regenerates the same portable single-file manual you'd
  get from the original site's download feature.
- The "↗ Share" button (native share sheet where supported, clipboard-copy fallback).
- The mobile hamburger menu / sidebar drawer.

It's built as plain HTML/CSS/vanilla JS (no React, no build step at request time) so it runs
as a static site with no server-side software — same as the earlier export, just with the
full app experience instead of only the Manual tab.

## Publish

1. Upload every file in this folder to the root of a GitHub repository.
2. Open the repository's **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the branch containing these files (normally `main`) and the `/ (root)` folder, then save.
5. GitHub will show the public address when publishing finishes.

The included `robots.txt` and page metadata ask search engines not to index the site
(`noindex,nofollow,noarchive`). This discourages discovery but does not make the site
private: anyone with the URL can still open or forward it.

## Files

- `index.html` — page markup and embedded chapter/diagnostic content (generated by `build.mjs`
  from `manual.md`, so re-running the build after editing the manual regenerates this file).
- `app.js` — all interactivity: view switching, search, chapter routing, download, share.
- `404.html` — identical copy of `index.html`, served by GitHub Pages for unknown paths.
- `favicon.svg`, `og.png` — icon and social-preview image.
- `robots.txt` — opts the site out of search-engine indexing.
